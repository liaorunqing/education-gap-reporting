# Reproducibility scope in version 1.1.0

Three workflows are separate.

1. `reproduce.py --verify --checks --tables`: integrity, exact finite-population checks, nine numerical point/interval metrics for 768 frozen rows, and four post-score descriptive tables. Counts are exact; floating CSV values use strict roundoff tolerance. This does not resample households.
2. `scripts/acs222_fetch_sources.py` followed by `scripts/acs216_raw_reconstruction.py`: official raw-ZIP rebuild of the **used CT 2024/1000-household path**, including source/risk model refits, 2,000 repetitions and all 16 methods. No pretrained model or derived observation array is an input. Only source checksums, aggregate source-count audits and fixed configuration accompany the source files. In the original environment all 29 compared arrays were numerically exact. Fivefold risk diagnostics and unused learner families do not feed this CT path and are excluded. Other states/budgets are not newly rebuilt.
3. `scripts/acs223_sipp_reproduce.py`: raw SIPP historical linkage/retention and a separately planned five-control conditional pilot. Source files are obtained from Census; person records, model inputs and identifiers are generated only in a private local work directory. The public release contains aggregate results and simulation outputs only. Complete-case target membership depends on future follow-up, so this is not a prospective field validation.

Original ACS data and final labels were already scored before this reconstruction. The old result files remain frozen and are used as references only after rebuilding. Reproduction is not a new independent holdout. The SIPP years represent a new data-source feasibility pilot; their self-reported/allocated qualification values are not independent verified degrees.

The 1.0.x release exposed only summary replay and raw descriptive targets; it did not claim a turnkey model rebuild. This version adds a tested, narrower full used-path rebuild without asserting reconstruction of the whole historical programme. No DOI is assigned and no Zenodo deposit is claimed. Field-roster coverage, nonresponse adjustment and costs remain separate research tasks.

Timing qualification: the 2024 SIPP public file was released on 24 July 2025, after the February–June 2025 follow-up fieldwork. Earlier-reference final weights are not thereby proven available before selection. Historical responses can precede recontact internally, but this retrospective public-file pilot does not validate an as-of operational extract or preselection availability of final weights. See data/sipp_audit/availability_timing_audit.json.
